# Agent Note: Compare dated default model prices without changing billing

Status: implemented

[English](2026-11-01-default-price-comparisons.md) | 中文

## 问题

统一的充值折扣会把支付金额与模型价格混为一谈，也会隐藏输入输出及媒体规格的差异。公开价格响应还可能包含充值页不需要的内部字段。

## 决策

Host 通过有界、无凭据的读取提供默认零售价与带核对日期的官方参考价。每行保留准确单位、规格、方向、出处和比较条件。白名单排除采购成本及渠道标识；缺失或无效的参考元数据不能生成折扣宣传。

充值页明确说明比较采用默认报价，实际收费以提交时报价为准。页面逐行计算十进制比例，以保守方向处理展示精度，并提供原始金额和官方出处。比较读取独立取消及重试，不能创建支付订单或生成请求。[Host 参考](../../../../packages/host/credits-index/README.zh.md)与[客户端参考](../../../../packages/client/ui-credits/README.zh.md)负责操作细节。

## 考虑过的替代方案

**宣传所有模型统一折扣。** 输入、输出及媒体规格的价格不同，统一倍率会隐藏影响结果的条件。

**把默认零售价当作账号报价。** 当前账号数据不能确认所有分组或订阅调整。计费仍由现有报价与提交路径负责。

**透传整份价格文档。** 公开比较字段已经足够，复制无关字段会扩大披露并让页面耦合内部定价细节。

## 影响

用户可以核对准确且有日期的比较，无需改变支付金额或所选模型。参考价格会过时，需要服务器端维护。旧 API 缺少参考元数据时，支付流程仍可用，比较卡不展示。免费测试以实际公开 API 响应样本经过 Host 和构建后的浏览器验证，不代表当前供应商可用性或付费生成质量。
