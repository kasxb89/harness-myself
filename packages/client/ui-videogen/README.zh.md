# 视频创作

[English](README.md) | 中文

## 概述

使用可编辑描述，以及所选模型支持的图片、视频或音频参考素材创作视频片段。已发布脚本和可选的 AI（人工智能）帮写帮助在生成前准备描述。播放、下载已保存片段，切换模式时保留草稿。生成使用当前账号，连接失败可能导致结果未知。

## 使用本包

API 调用、模板媒体和产物预览通过 [`appPath`](../ui-primitives/README.zh.md#use-this-package) 保留应用部署前缀；本地 blob 预览保留原地址。

在桌面统一 AI 创作入口的视频模式中准备片段，再明确提交生成。

创作框只在既有媒体目录声明支持时提供文生视频、图生视频、首尾帧和参考素材入口。其他创作方式的素材仍保存在草稿中，但不会发送到生成请求。首尾帧模式必须提供两张图片。切换模型或创作方式时保留素材；生成只发送当前创作方式和模型接受的输入。注入的创作内容目录提供后台发布的镜头脚本、分类、预设指令、标题和输入占位文案，并遵循后台排序；草稿脚本和停用分类不显示。英文缺失时使用对应中文。封面和可选演示视频使用真实创作资产，缺失时不展示虚构图片或分镜。加载、空内容和失败显示实际状态，失败可重试，不回退内置业务内容。镜头脚本卡支持分类筛选与预览；填入脚本会追加可编辑文字，不会提交生成请求。「我的作品」列出真实保存的视频产物，支持播放和下载。

统一素材入口接受图片，以及当前模型声明支持的 MP4/MOV 视频和 MP3/WAV 音频，可混合批量选择。浏览器未提供格式标识时按支持的后缀识别，再由宿主校验实际字节。从文生模式添加图片时，支持参考图则切换参考素材模式，否则在支持图片帧时切换图生模式并将首张设为首帧。用户也可从保留图片中明确指定首尾帧。图片素材池至少保留九张帮写参考图，不受较小的生成数量限制；模型声明更大数量时可继续保留。原图单张可达 32 MiB；宿主将 HEIC 等支持格式规范成供预览和模型读取的 PNG/JPEG，转换后单张不超过 6 MiB、合计不超过 12 MiB。动图和多页图片使用第一帧。视频单个不超过 32 MiB，音频单个不超过 15 MiB 并支持试听。当前生成素材合计不超过 48 MiB。批量上传保留成功文件、继续处理后续文件，并逐项显示失败文件名。同一时间仅允许一项上传或生成操作。生成请求只执行一次；结果不确定时保留草稿与上一条结果，提示先检查已保存作品。只要还有素材或帧引用，预览就保持有效；移除图片素材也会清除其首尾帧引用。

所有创作方式共用提示词上方的一个紧凑“添加素材”入口。上传前就按当前模型显示图片上限，以及支持的视频、音频格式、数量和单文件大小。参考视频支持直接播放；各创作方式及切换模型后，保留的视频和音频仍可查看、移除。已上传素材在同一区域以紧凑缩略图网格展示，文件名单行收起，卡片标记当前使用的首尾帧。帧模式只提供所需的角色选择框，从同一素材池指定图片，不另设上传入口，也不在每张卡片重复选择操作。只有参考输入、没有帧槽的模型仅显示参考素材模式，避免图生与参考入口重复。进入图生或首尾帧模式且尚未选择首帧时，会选中已有图片；用户主动清除或删除后，即使切换页面重新挂载也不会重新选中。自动选择的记录保留在窗口草稿内，读取已有图片前会检查当前账号归属和代次。首尾帧标记与选择框仅表示当前模式实际发送的帧；参考模式保留缓存选择，但不会将其标为正在使用。页面明确显示本次生成实际发送的素材，生成按钮旁说明缺少输入或正在帮写、上传的原因。上传失败区分图片张数、转换后单张大小和图片总大小；合计超限会列出已有素材与新图各自的 MiB 数值。

提示词编辑器接入共享的 [AI 帮写](../ui-prompt-assist/README.zh.md)，传入当前描述、视频设置，以及去重后的全部首尾帧和参考图片，包括其他创作方式保留的图片。页面明确提示视频和音频参考仅用于生成；图片超过九张时停用帮写，不截断素材。明确发起的帮写成功后直接更新主提示词并聚焦，修改意见基于当前文字继续重写，不会开始生成视频。帮写期间锁定上传、生成、创作方式和设置控件，主提示词仍可编辑。最终比对当前文字、账号代次、素材、设置和媒体操作状态，拒绝覆盖期间发生的变化。

窗口草稿在面板重新挂载后保留参考素材所属账号和上传代次。只有确认当前账号与素材所属账号一致，才向 AI 帮写传入父页面图片。切换账号或退出登录时，清空首尾帧及全部图片、视频和音频参考，并释放预览 URL。旧账号的迟到上传不能恢复素材、覆盖当前上传的反馈或解除其锁定，即使切回原账号也会被忽略。带参考素材的生成请求会先重新核验当前账号；账号变化后，用户须先确认已清空的素材再生成。

“视频参数”分组始终展示已声明的比例、分辨率、时长、档位、种子与音轨控件，并列展示当前画面比例、分辨率与时长；使用精确像素尺寸的模型显示尺寸和时长，不提供不支持的比例控件。之前的时长不可用时优先采用模型声明的默认时长。面板按比例卡片、分辨率、时长和已声明的音轨能力分组；音轨固定的模型显示真实限制，不提供开关。目录提供分辨率对应的时长菜单时，缺失分辨率条目不会回退全局时长；只有模型明确声明后才出现 30 秒选项。切换模型、分辨率或创作方式后，会在生成前可见地修正不兼容的选择。初次选中已声明的档位，保留档位不受新模型支持时也会替换为有效档位。Seedance 2.5 的画面帧模式仅展示声明的「跟随素材」比例，添加帧前也保留可见的必选项。显式的在线比例菜单约束此选择；没有合法交集时禁止生成并说明配置不匹配。「跟随素材」要求当前创作方式实际发送图片或视频，保留的隐藏素材或纯音频参考不能开启该比例。超出新模型上限的素材仍保存在草稿中，并提示先移除，不会静默截断后生成。

模型声明的初始时长只有仍在当前菜单中、且未保留有效选择时才会使用。因此 BlackRxAI 型号以各自声明的 30 秒或 15 秒开始，并提供实际宽高形式的请求尺寸，不按线路名称推断产物像素。已受理待确认或结果未知的提交，即使停止了本地等待，也继续显示未确认提示。聊天的创作任务卡可查询保留的原任务，不重复付费生成。 视频创作框也会在重新挂载后恢复并查询当前账号所属的原回执；视频计划内的参考图与素材任务不会锁定普通视频生成。缺失或无法读取的回执继续保留保护状态，查询不会再次提交生成。

原任务核对仅限制付费提交。尚未选择聊天、原提交未确认或回执读取失败，不会禁用模型选择、可编辑参数或已发布脚本预览。实际上传、生成和 AI 帮写期间仍保护可修改的输入。音频输出未知时说明以上游成片为准，不宣称必定静音，也不提供接口不支持的音频开关。

生成按钮禁用时，会在按钮旁说明当前原因，包括提示词已填写但原任务仍在核对或核对失败的情况；辅助技术也能读取按钮关联的说明。原任务反馈及核对、查询入口直接位于创作框下方。核对成功后恢复提交，保留提示词，不自动发起生成。

已保存作品来自产物索引中的当前及保留的历史输出根目录，支持自定义目录与 Windows 路径。在[产物页面](../ui-artifacts/README.zh.md) 管理目录、名称与可恢复删除；创作作品网格不会改写之前的聊天链接。

所选模型提供随机种子控件时，非空种子必须是安全整数。无效值保留在草稿中，并在生成前显示参数错误，不会省略用户选择的种子后提交。

生成前先选择工作区聊天。等待期间切换聊天，请求仍保留发起时的聊天与账号。AI 创作只保留图片、视频两个页签；在该聊天右侧打开[创作](../ui-creative/README.zh.md)，查看时间轴、人物、素材、保留任务和已保存产物。历史播放和下载保留各产物的工作区标识，不混用不同挂载中的相同路径。

图片和视频任务受理后保留原回执，排队或处理中显示生成中。临时状态读取、下载或保存失败时保留原任务与较早产物。**查询原任务** 只查询并保存已有任务，不再次提交生成。待处理或结果未知时，跨页面重挂载仍阻止重复生成；确认终态失败后才解除限制。没有任务编号的提交保留为状态待确认，不能盲目重提。

生成、模型目录及素材失败按已观察到的错误码区分连接失败、超时、输入不合法、权限、本机处理、模型服务异常与已确认的服务异常；仅明确的繁忙或限流使用繁忙提示。原因未确认时使用中性说明，不展示原始消息或代码。传输保留 HTTP 状态，JSON 解析失败仍归为响应异常，不判为网络连接失败。登录、产品积分不足、取消、文件校验及付费结果未知保留安全的后续说明。上传失败仍点名对应素材，生成失败不自动重发请求。

## 模型体验

### 视频提交与提示词帮写

#### 模型接收的内容

本插件不添加工具或 Session 事件。明确点击生成视频后，向媒体接口提交可见的 `prompt`、当前模型设置和当前创作方式的素材。AI 帮写是独立的文字或视觉请求，使用当前草稿及全部保留图片。

#### token 影响

生成遵循所选媒体模型的计量方式。[共享帮写插件](../ui-prompt-assist/README.zh.md) 维护提示词帮写的计费说明。脚本预览与分类筛选不消耗模型 token。

#### KV Cache 影响

客户端不管理提供方缓存或模型对话。脚本预览与分类筛选不影响 KV 缓存；明确提交的生成与提示词帮写各自使用提供方负责的请求。

## 已知限制与延后工作

<a id="known-limitations-and-deferred-work"></a>

- 片段接口等待最终产物路径，不提供客户端生成取消或发布操作。聊天右侧的创作项目提供可编辑时间轴和保留任务列表；较早未关联项目的产物缺少项目元数据。作品网格不会自动恢复创作框设置。音频参考与开关遵从模型声明。草稿在当前窗口切换模式时保留，重新加载后重置。
