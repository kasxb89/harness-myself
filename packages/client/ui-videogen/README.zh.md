# 视频创作

[English](README.md) | 中文

## 概述

使用可编辑描述，以及所选模型支持的图片或视频参考素材创作视频片段。已发布脚本和可选的 AI（人工智能）帮写帮助在生成前准备描述。播放、下载已保存片段，切换模式时保留草稿。生成使用当前账号，连接失败可能导致结果未知。

## 使用本包

在桌面统一 AI 创作入口的视频模式中准备片段，再明确提交生成。

创作框只在既有媒体目录声明支持时提供文生视频、图生视频、首尾帧和参考素材入口。其他创作方式的素材仍保存在草稿中，但不会发送到生成请求。首尾帧模式必须提供两张图片。切换模型或创作方式时保留素材；生成只发送当前创作方式和模型接受的输入。注入的创作内容目录提供后台发布的镜头脚本、分类、预设指令、标题和输入占位文案，并遵循后台排序；草稿脚本和停用分类不显示。英文缺失时使用对应中文。封面和可选演示视频使用真实创作资产，缺失时不展示虚构图片或分镜。加载、空内容和失败显示实际状态，失败可重试，不回退内置业务内容。镜头脚本卡支持分类筛选与预览；填入脚本会追加可编辑文字，不会提交生成请求。「我的作品」列出真实保存的视频产物，支持播放和下载。

插件沿用既有登录状态、媒体目录、素材上传、生成与产物接口。统一添加素材入口独立于模型能力提供图片上传。首尾帧与参考图片共享最多六张不同图片、单张 6 MiB、合计 12 MiB 的限制；参考视频沿用服务端 32 MiB 上限。空文件无法上传。批量上传失败时保留已成功上传的素材，显示失败信息并恢复控件。创作框同一时间仅允许一项上传或生成操作。生成请求只执行一次；网络异常时保留草稿与上一条结果，并提示先检查已保存作品，再决定是否重新提交。预览 URL 在模式切换后继续有效，在移除、替换或插件卸载时释放。

提示词编辑器接入共享的 [AI 帮写](../ui-prompt-assist/README.zh.md)，传入当前描述、视频设置，以及去重后的全部首尾帧和参考图片，包括其他创作方式保留的图片；视频标识绝不会传给帮写。明确发起的帮写成功后直接更新主提示词并聚焦，修改意见基于当前文字继续重写，不会开始生成视频。帮写期间锁定上传、生成、创作方式和设置控件，主提示词仍可编辑。最终比对当前文字、账号代次、素材、设置和媒体操作状态，拒绝覆盖期间发生的变化。

窗口草稿在面板重新挂载后保留参考素材所属账号和上传代次。只有确认当前账号与素材所属账号一致，才向 AI 帮写传入父页面图片。切换账号或退出登录时，清空首尾帧及全部图片、视频参考，并释放预览 URL。旧账号的迟到上传不能恢复素材、覆盖当前上传的反馈或解除其锁定，即使切回原账号也会被忽略。带参考素材的生成请求会先重新核验当前账号；账号变化后，用户须先确认已清空的素材再生成。

视频参数入口并列展示当前画面比例、分辨率与时长。内联展开面板按比例卡片、分辨率、时长和音轨分组；音轨固定的模型显示真实限制，不提供开关。切换模型后，生成前展示该模型支持的参数。

## 模型体验

### 视频提交与提示词帮写

#### 模型接收的内容

本插件不添加工具或 Session 事件。明确点击生成视频后，向媒体接口提交可见的 `prompt`、当前模型设置和当前创作方式的素材。AI 帮写是独立的文字或视觉请求，使用当前草稿及全部保留图片。

#### token 影响

生成遵循所选媒体模型的计量方式。[共享帮写插件](../ui-prompt-assist/README.zh.md) 维护提示词帮写的计费说明。脚本预览与分类筛选不消耗模型 token。

#### KV Cache 影响

客户端不管理提供方缓存或模型对话。脚本预览与分类筛选不影响 KV 缓存；明确提交的生成与提示词帮写各自使用提供方负责的请求。

## 已知限制与延后工作

<a id="known-limitations-and-deferred-work"></a>

- 服务端生成接口等待最终产物路径，不提供客户端任务队列、取消、发布或可编辑时间线。当前素材接口不接收音频，因此不显示音频参考上传；只有声明支持切换的模型才显示输出音轨开关。产物列表不包含原始提示词或生成参数，无法从作品恢复这些内容。草稿可在同一窗口内切换模式后保留，刷新页面后重置。
