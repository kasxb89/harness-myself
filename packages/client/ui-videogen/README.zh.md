# 视频创作

[English](README.md) | 中文

本浏览器插件为桌面渲染器中的统一 AI 创作入口提供视频模式。图片与视频页签选择既有的独立面板；声明式窗口 store 在面板重新挂载后保留视频描述、参数、参考素材预览、结果和忙碌状态，不将草稿持久化到磁盘。

创作框只在既有媒体目录声明支持时提供文生视频、图生视频、首尾帧和参考素材入口。其他创作方式的素材仍保存在草稿中，但不会发送到生成请求。首尾帧模式必须提供两张图片。切换模型后，超出新模型上限的素材会被移除并释放预览，界面提示用户确认保留的素材。镜头脚本卡支持分类筛选与可编辑预览；填入脚本会追加文字，不会提交生成请求。「我的作品」列出真实保存的视频产物，支持播放和下载。

插件沿用既有登录状态、媒体目录、素材上传、生成与产物接口。上传素材须非空且不超过服务端规定的 32 MB。批量上传失败时保留已成功上传的素材，显示失败信息并恢复控件。创作框同一时间仅允许一项上传或生成操作。生成请求只执行一次；网络异常时保留草稿与上一条结果，并提示先检查已保存作品，再决定是否重新提交。预览 URL 在模式切换后继续有效，在移除、替换或插件卸载时释放。

## Model Experience

本插件不添加模型提示词、工具或 Session 事件。只有明确点击生成，才向既有媒体接口提交可见描述、当前模型设置和当前创作方式的素材。脚本预览与分类筛选不消耗模型 token 或 KV 缓存。

## Known Limitations and Deferred Work

服务端生成接口等待最终产物路径，不提供客户端任务队列、取消、发布或可编辑时间线。当前素材接口不接收音频，因此不显示音频参考上传；只有声明支持的模型才显示输出音轨开关。产物列表不包含原始提示词或生成参数，无法从作品恢复这些内容。草稿可在同一窗口内切换模式后保留，刷新页面后重置。
