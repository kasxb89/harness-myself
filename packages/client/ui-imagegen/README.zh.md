# 图片创作工作区

[English](README.md) | 中文

## 概述

根据可编辑提示词和模型支持的参考素材创作图片，可使用已发布模板和可选的 AI（人工智能）帮写。预览、下载已保存作品，或将作品复用为参考素材。草稿在当前插件生命周期内跨模式切换后保留。生成使用当前登录账号，连接失败后仍可能在上游继续执行。

## 使用本包

API 调用、模板媒体和产物预览通过 [`appPath`](../ui-primitives/README.zh.md#use-this-package) 保留应用部署前缀；本地 blob 预览保留原地址。

在桌面 AI 创作工作区的图片模式中准备提示词，选择模型接受的输入，再明确提交生成。

**图片规格**区域始终展示所选模型声明的选项，包括像素尺寸、分辨率档位、张数、质量和可选输出设置。文生图和图生图使用相同控件。只有命名分辨率档位的模型不会出现未声明的像素尺寸或比例选项。切换模式保留草稿；切换模型清除不受支持的选择。

注入的创作内容目录提供管理后台发布的模板、分类标签、风格指令、标题和提示词占位文案。分类与模板遵循后台配置的排序，草稿模板和停用分类不显示。英文内容缺失时使用对应中文。真实封面资产通过创作资产接口加载；没有封面时使用纯文字卡片。目录显示实际的加载、空内容和失败状态，失败后提供明确的重试入口，不回退内置业务内容。选择模板会填入可编辑的提示词，风格按钮会将配置的后缀追加一次；两者均不开始生成。作品网格列出已有的图片生成产物，支持原图预览和下载，并且可将作品上传为素材，不受模型能力限制。

提示词编辑器接入共享的 [AI 帮写](../ui-prompt-assist/README.zh.md)，传入当前文字、全部保留的图片素材和生成设置。明确发起的帮写请求成功后直接更新主提示词并聚焦编辑器，后续修改意见基于当前文字继续重写。帮写期间锁定上传、生成和设置控件，主提示词仍可编辑。最终比对当前提示词、账号代次、素材、设置及媒体操作状态，防止迟到结果覆盖期间发生的变化。帮写不会提交图片生成请求。

窗口草稿在面板重新挂载后保留参考素材所属账号。只有确认当前账号与素材所属账号一致，才向帮写传入父页面素材。切换账号或退出登录时清空参考素材选择并释放预览。旧账号的上传不能追加素材、替换反馈或解除新上传的锁定，即使切回原账号也会被忽略。带参考素材的图片生成会在发送付费请求前重新核验当前账号；账号变化后清空素材，并提示用户先确认再生成。

素材区将上传入口和全部保留缩略图集中在提示词上方，长提示词也不会把素材挤到下方。既有 Credits 媒体目录提供全部模型及其接受的参数，并在声明支持时单独提供分辨率档位。切换模型时保留素材，清除不受支持的参数选择。素材最多接受六张 PNG、JPEG/JFIF、WebP、AVIF、GIF、BMP、TIFF、HEIC 或 HEIF 图片，纯文生模型也可添加。单张原图不超过 32 MiB；宿主核验真实图片字节并转换为模型支持的 PNG 或 JPEG，动态图片使用首帧。转换后的素材合计不超过 12 MiB。页面保留成功添加的图片，逐张列出失败文件名及原因，并报告添加、失败与转换数量；单张上传失败不影响同批后续文件。帮写接收全部素材。图片生成只使用所选模型接受的前几张图片，纯文生模型不接收图片输入；页面说明这一区别。读取已保存作品和上传素材共用一个上传锁，跨模式切换时也会阻止生成。追加素材按当前数量及字节预算校验。上传失败或确认的生成拒绝保留草稿并恢复控件。生成连接中断时保留原提交，并提供安全的原任务查询。

图片和视频任务受理后保留可用的原项目、操作、任务及请求编号，排队或处理中显示生成中。临时状态读取、下载或保存失败时保留原任务与较早产物。只有宿主允许查询原回执时才显示**查询原任务**，只查询并保存已有任务，不再次提交生成。待处理或结果未知时，跨页面重挂载仍阻止重复生成；确认终态失败后才解除限制。没有任务编号的提交保留为状态待确认，并提示核对原记录与计费。读取或查询失败均保留保护状态，页面不自动重新提交生成。

原任务准入只阻止付费生成。尚未选择聊天或旧任务未确认时，用户仍可准备模型、参考图、参数和模板；实际上传、生成及 AI 帮写仍保留输入锁。修改草稿不改变原任务所属的聊天与账号坐标。

已保存作品来自产物索引中的当前及保留的历史输出根目录，支持自定义目录与 Windows 路径。在[产物页面](../ui-artifacts/README.zh.md) 管理目录、名称与可恢复删除；创作作品网格不会改写之前的聊天链接。

生成前先选择工作区聊天。请求捕获准确的聊天及登录账号，保留包含提示词、素材引用、任务及已保存图片的项目。AI 创作只保留图片、视频两个页签；在聊天右侧打开[创作](../ui-creative/README.zh.md)，管理对应的时间轴、人物、素材与任务。产物预览及用作参考保留来源工作区坐标，多个挂载存在相同路径时也不会混用。

生成与模型目录失败根据已观察到的错误代码或 HTTP 状态，区分网络中断、超时、输入无效、权限、明确繁忙、服务故障、模型服务故障及本机存储失败。未知错误保留原因未确认的说明。Fetch 传输失败提示检查本机网络、VPN 或代理；任意异常不会被判定为网络或服务器原因。登录和产品积分不足保留恢复说明；每张上传失败的图片仍显示文件名及安全的格式、大小或转换原因。Host 的三种本地参考图校验或上传失败也保留安全的文件名、原因和尚未提交生成的说明。页面不渲染其他响应消息或代码。生成结果未知或已受理时保留原任务恢复，失败的付费请求不会自动重发。

## 理解实现

<details>
<summary>实现细节 — 点击展开</summary>

[客户端入口](src/client/index.ts) 注册一个 AI 创作侧边栏入口和 `imagegen` 主面板。图片与视频页签通过布局回调选择相邻模式的面板。注册时创建的[草稿状态](src/client/draft-store.ts) 在面板切换后保留图片提示词、所选模型、参数、参考素材选择、操作状态、原任务回执和反馈，不写入磁盘。启用生成前，页面读取当前账号与聊天所属的宿主项目记录，因此重新加载后仍能恢复待确认任务的保护。只有确认原任务结束才解除已保留的保护。原任务查询进行时仅在页面可见期间轮询；账号变化或页面卸载会取消读取。参考素材的预览 URL 归插件所有，在素材移除、所属账号变化或插件卸载时释放。

没有已保留的项目与操作坐标时，表单恢复宿主标记为 `source: 'ai-creation'` 的提交。已确认的聊天任务不锁定表单；缺失来源的旧任务继续保留保护，除非保留的视频项目编号或工具调用来源能确认其属于聊天。已经捕获的原任务坐标始终优先：记录缺失、读取失败和结果未知都保留保护，其他待处理任务不能替换原任务，只有原任务确认终态才解除限制。

</details>

## 模型体验

### 图片提交

#### 模型接收的内容

明确提交图片生成时，`/credits/api/image/generate` 接收用户编辑的提示词、所选模型参数和参考资产标识。AI 帮写是独立、明确发起的请求，使用当前草稿及全部保留的图片素材。选择模板、筛选、预览图片和切换面板均不请求模型。核对记录只读取当前所属的本地创作项目；查询已受理任务时，仅将原会话、项目和操作编号提交到 `/credits/api/creative/image/recover`，由宿主查询已有任务，不再次提交生成。

#### token 影响

用户控制提示词与所选参考素材。所选图片提供方负责输入限制和 token 计量；本包不添加会话消息。

#### KV Cache 影响

提交提示词会发起独立的、由提供方负责的图片请求。本包不管理会话上下文或提供方缓存。

## 已知限制与延后工作

<a id="known-limitations-and-deferred-work"></a>

- 较早未关联项目的产物没有项目元数据。新的账号及聊天关联请求在创作项目中保留提示词与素材引用；作品网格不会自动恢复创作框设置。
- 模板提供提示词文字；输出数量和支持的生成输入仍受所选模型限制。
- 创作网格不提供收藏、发布或取消生成操作；文件管理位于产物页面。
- 草稿仅在当前插件生命周期内跨模式切换后保留。重新加载应用会清空编辑草稿；待确认任务的保护从所属宿主记录中恢复，中断的请求仍可能在上游继续执行。缺少任务编号的未知记录无法在此页面查询或解除保护。
