# 余额与用量

[English](README.md) | 中文

## 概述

查看当前账号的积分，使用手机号登录，并按日期和模型分析用量。需要更多积分时打开独立的充值面板。工作区示例帮助起草视频请求，不会发送文字或开始计费操作。使用量读取当前登录账号的消费账单记录，最新消费可能稍后出现。

## 使用本包

账号、充值和用量请求通过 [`appPath`](../ui-primitives/README.zh.md#use-this-package) 保留应用部署前缀。

余额面板展示当前账号的积分、手机号登录与使用量分析，独立的充值面板负责支付。两页共用现有会话和余额状态；用量查询由积分宿主（`host/credits-index`）确定当前登录账号。

余额与手机号登录页会告知登录后的客户端上线、在线常驻及前台使用统计。这些统计不含输入、聊天正文、屏幕内容、本地文件路径或硬件指纹。普通 Web 没有原生活动发送器。

注入的 `creditsSession` 源向其他客户端插件开放同一个账号快照。订阅期间保留共享账号刷新，最后一个订阅释放时停止计时器和焦点监听。读取失败或响应格式异常时保留最近确认的账号和余额，并明确显示刷新错误；空 payload 不代表读取成功。网络中断、超时、登录、权限和限流分别提供处理提示。服务端要求等待时禁止反复刷新，不清除登录。账号有效性尚未确认时，余额页保留“退出登录”，同时继续禁止依赖账号核验的操作。只有本机宿主确认已无登录后，退出才会清除界面账号；确认失败时保留恢复入口，本机已退出但服务端注销未确认时单独提示。`signOutTimeoutMs` 限制退出请求和确认的总时长，默认 20,000 ms，范围 1,000–120,000 ms。切换账号会清除旧余额，迟到读取不能覆盖当前登录的数据。

桌面欢迎页通过 `?panel=credits` 打开余额面板及手机号登录表单。客户端仅消费一次该入口请求，只从地址中移除 `panel`，保留其他查询参数和 hash。打开页面不会创建账号会话或配置 API Key。手机号验证成功后刷新账号会话，并回到现有聊天工作区，不创建或清空其 Session；响应不含注册奖励时也正常完成登录。之后主动打开余额或充值页面、刷新账号或余额，都会保留用户选择的面板。

手机号表单区分验证码无效或过期与登录服务暂时不可用。失败请求保留原请求标识，供用户手动重试。短信发送结果不明时保留可用的验证请求：用户可以输入已收到的验证码，或查询同一请求，不会再次发码。只有明确的 `not_sent` 发送回执才允许再次点击时创建新短信请求；不可用响应缺少发送数据时，保留原请求标识并提示结果未确认。服务端冷却使用绝对截止时间；重新打开页面恢复待处理请求标识，不保存验证码或自动提交请求。验证请求过期后仍保留结果未确认的兑换，供用户输入原验证码手动恢复；成功回执是否仍可回放由 API 判断。API 声明 `2fa` 时，表单接受验证器验证码或备用码；其他方式保持未支持。安全验证结果不明时，必须重新进行手机号认证，不重放该验证请求。

手机号表单默认中国大陆（`+86`），提供马来西亚（`+60`）、日本（`+81`）、美国／加拿大（`+1`）及完整国际号码入口。规范国际号码保留用户输入的数字；海外验证请求仅准备登录，不表示已发送短信。海外用户在原验证码输入框填写运营人员首次通过微信交给本人的独立登录码。表单接受 16 位固定码及原六位临时码，国内短信保持六位。海外码输入掩码显示并声明关闭自动填充，国内仍为明文短信输入及一次性验证码提示；这项输入保护不新增设置密码流程或持久保存登录码。固定码可重复登录，后台重置或停用后失效；临时码仍沿用原有效期及一次性规则。重新准备验证请求时可继续使用原固定码，请求过期不代表固定码过期；结果未确认的兑换仍使用原请求标识恢复。恢复待处理请求时也按号码显示对应提示。修改手机号或区号会清除表单原验证请求和验证码，只有明确操作才提交新请求。手机号和登录码均可粘贴；匿名表单不公布白名单归属，也不读取运营登录码。

### 充值

充值接受以元为单位的正整数金额，显示宿主换算后的积分，不把上游 quota 当作积分。创建订单后显示微信二维码，并轮询该订单直到收到终态。读取失败会保留二维码和余额，提示支付结果尚未确认，并可重新读取同一订单的状态，不会创建第二笔订单。停止查询会中止当前 HTTP 读取，但不会取消支付。未知支付状态会停止自动查询并明确提示尚未确认，同时保留同一订单供重新查询。切换订单、账号或关闭面板会丢弃迟到的响应。确认到账后会重新读取余额，不复用付款前已发起的读取，较早的响应也不能覆盖新读取的结果。服务端冷却与账号隔离仍然有效；余额读取失败也会保留已确认到账的状态。

每次创建订单和查询状态都绑定页面显示的账号及已核对的登录归属。确认金额后先刷新共享会话；如果发现账号或登录已变更，会清除旧二维码，新显示的账号需要用户再次明确确认金额。身份不符时提供“刷新账号信息”，无法核对归属时禁止下单。旧 Host 仍可提供普通余额读取，但充值必须支持登录归属契约。服务端要求等待时也会禁用财务操作；下单失败或结果未确认都不会自动重提。

充值表单下方以限高、可滚轮滚动的网格展示公开参考型号，每个型号一张卡片，桌面每行四张，窄屏改为两张或一张。卡片展示一个明确的价格规格，不代表类别整体折扣或当前账号的可用数量；点击后在可滚动弹窗中查看同规格价格、来源、条件和核对日期，复用共享的键盘关闭与焦点恢复。对比采用平台默认报价，与充值金额和账号最终报价分开，输入与输出分别列出，十进制计算按保守方向显示折扣。缺少官方元数据或旧 Host 不产生优惠宣传。账号变化会关闭旧详情并丢弃迟到回复；局部读取失败不影响支付或生成。

### 注册场景问卷

手机号注册后，只有当前账号经服务器确认的待填资格才会自动打开场景问卷。已有账号、稍后填写及已提交的问卷都不自动弹出。用户可多选使用场景，并选填最多 1,000 个 Unicode 字符。“稍后填写”关闭弹窗且不阻挡产品使用，余额页入口可以继续填写。跨设备的已提交状态以 API 记录为准，客户端不根据本地首次使用或赠送积分猜测是否新注册。

问卷帮助用户更好使用产品。API 可配置最多 64 个场景、顺序和中英文标签，调整选项不需要发布客户端。配置变化保留草稿，并明确显示已停用的选择，直到用户自行移除；只有用户再次明确核对后提交才会发送当前配置版本。已完成的答案保留提交时配置，旧 API 仍使用原九项问卷。

根级控制器不随登录页关闭而消失，账号归属变化时清除草稿并丢弃迟到响应。提交结果未确认时先查询当前账号的权威问卷；若读取也失败，保留并锁定原答案，等待显式重新核对。关闭该弹窗仍保留可用的余额页入口，不重复提交。旧 Host 或 API 不支持问卷时，普通登录和使用不受影响。

### 使用量分析

今日、近七天和近三十天均按北京时间自然日统计，截至查询时刻。模型筛选同时作用于消费积分、计费记录和 Token 总量、每日趋势、模型排行及对应明细表。同一周期刷新失败时保留最近成功读取的数值，并标明这是上次读取结果。限流时显示服务端要求的等待时间，等待结束前禁止刷新和切换周期。切换周期后先清除旧数值并显示加载状态。切换账号会卸载上一账号的分析，迟到的响应不会覆盖当前选择。

用量响应属于其他账号或登录时，“重试”会先核对当前共享会话，再读取该身份的统计，恢复其他窗口带来的身份变化，避免反复用旧面板身份查询。同一账号重新登录也会递增本地账号代次；登录归属不变的普通令牌续期保持原代次。

图表展示退款抵扣前的累计消费、消费账单记录以及 Token 总量。成功且完整的查询中，无记录的日期汇总为零。空响应显示空态；统计不可用、格式异常或数值溢出均显示错误，不编造图表数据。标签、单位和查询状态文案均跟随产品语言与主题。

### 聊天回复积分

聊天输入框显示“当前会话回复积分”，每轮结尾显示“本轮回复积分”。两者通过 `/credits/api/chat-usage` 读取当前登录账号与已附着会话的可核对账单，不从 Token 换算积分。这里只统计主会话已记录的回复模型请求，不含图片、视频任务、独立 AI 帮写、子会话、上下文整理、自动标题等后台辅助调用；统计完成后的详情提供余额使用明细入口，全部消费以该明细为准。

只有本次读取确认全部已记录请求后，才显示准确积分。运行中或尚未完成的统计显示“积分统计中”；回执缺失或读取失败显示“统计暂未完成”。摘要和详情都不显示部分金额、请求笔数，也不把上一次金额当作本次总额。失败时提供简短刷新提示，不提示余额不足或充值。HTTP 401/403 或读取授权失效时提示重新登录。

常驻“刷新积分”按钮及轮次结束会发起读取；尚无已确认账单的待结算读取最多追加三次查询。其他未完成统计及读取失败或限流时需手动刷新。客户端 `chatUsageReadTimeoutMs` 默认 20,000 ms，范围为 1,000–120,000 ms。应将它配置为高于所属 Host 的统计期限及网络开销；Host 默认期限为 15,000 ms，各部署可自行调整。切换账号、退出登录或卸载控件会中止读取并丢弃迟到结果。共享账号快照的内存代次在身份变化时递增，同一账号退出再登录也隔离旧结果；普通余额刷新不改变代次。

### 聊天生成偏好

普通聊天输入框仅保留一个紧凑的“创作偏好”按钮。弹层的图片、视频页签可搜索授权型号并调整模型声明的静态参数。切换页签保留两份草稿；再次选择当前模型保留参数，选择其他模型会清空此前模型的参数。“清空参数”按钮可显式重置当前模型的参数。取消丢弃草稿，保存通过一次账号和修订号核对写入两类选择。原样保留的不可用选择仍明确显示，但不会阻止另一类修改；只有本次改成非法参数时才不能保存。参考文件仍附在单次请求中，视频时长仍表示单段默认时长。

Host 私有存储按账号和配置的部署保存偏好，重启后仍可恢复。启动只恢复本地偏好，用户打开编辑器或主动重新核对时才读取授权型号和价格目录。保存失败会保留两份草稿。冲突复核后，未编辑的选择采用最新确认值，已编辑的选择保持不变。账号变化会清空编辑器并丢弃迟到回复。定向子代理输入框不显示此入口。

普通提交在委托其他提示上下文提供方之前，捕获已经确认的设置元数据。本次消息明确指定的型号和参数优先，其次是个人偏好，再次是平台默认。编辑偏好只影响后续请求，运行中和已受理的生成保留原设置。保存不能替代视频逐作品报价和人工确认，普通文字也不会等待媒体目录或余额请求。

价格仅在编辑器内显示，单位为每张图片或每秒视频的积分估算。Host 按配置的积分换算率转换公开零售价，客户端精确比较十进制字符串，显示至多六位小数并向上取整。完整规格显示单值或范围，覆盖不全或计价条件不明时显示起价。价格缺失、格式错误、单位错误或无免费依据的零价保持待核价，不阻止选择。这些平台默认公开价只是参考，不是账号专属优惠、请求总价或生成授权；实际规格和账号报价决定扣费。

### 工作区示例

登录后的聊天输入框保留轻量“工作区示例”入口，仅在用户主动打开时展示，介绍用自然语言规划视频分镜、按模型单段时长限制生成，以及裁剪并拼接生成或上传的片段。这个参考弹窗与 AI 在聊天中针对具体请求提出的澄清问题各有用途。Escape、遮罩和关闭均可收起。客户端根内多个已挂载聊天同时最多打开一个示例弹窗；切换账号或卸载输入框会关闭它。状态仅留在内存中，不记录账号已读状态，也不会在首次访问时自动弹出。

选择示例会在打开弹窗时捕获的选区末尾插入普通文本，保留原有文本、引用和附件，不会发送或开始计费操作。草稿版本改变或输入框忙时拒绝插入并显示提示；重新打开示例可获取新的插入位置。

聊天新报告 `INSUFFICIENT_BALANCE` 时，本包接管现有额度通知插槽，显示本地化的“余额不足，请充值”和“去充值”按钮，按钮进入同一个充值页。切换或退出已观察账号会关闭通知。DeepSeek 的 `ACCOUNT_QUOTA` 通知继续由原功能负责；渠道及供应商额度错误不会触发云枢充值提醒。

媒体工具和后台任务的产品余额提示必须与当前登录的 `accountOwner` 精确匹配。缺失或过期的登录作用域不能打开充值弹窗，已记录的失败原因仍然显示。弹窗在渲染时及账号变更后都会重新校验作用域。

## 模型体验

### 账号面板与工作区示例

#### 模型接收的内容

本包不增加工具或模型调用。`/credits/api/usage` 的读取结果不进入模型输入。工作区示例在用户通过普通聊天输入框发送之前，只是尚未发送的草稿文本。已保存的媒体偏好元数据随普通请求受理传递；Credits Host 负责持久选择快照以及生成工具如何使用它们。

#### token 影响

账号分析、打开或插入示例均不消耗模型 token。后续 token 用量由常规聊天提交负责。

#### KV Cache 影响

账号分析及尚未发送的示例不改变模型的 KV 缓存。

## 已知限制与延后工作

<a id="known-limitations-and-deferred-work"></a>

- 使用量按当前账号的消费账单记录统计，最新消费可能稍后出现。消费记录数不等于接口请求次数，单独记录的退款不会从累计消费中扣除。本页没有输入输出 Token 拆分和逐次请求流水；部分图片、视频任务没有 Token 用量。宿主以当前账号身份授权读取账单记录。
