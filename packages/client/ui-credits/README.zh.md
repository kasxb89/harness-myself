# 余额与用量

[English](README.md) | 中文

## 概述

查看当前账号的积分，使用手机号登录，并按日期和模型分析用量。需要更多积分时打开独立的充值面板。工作区示例帮助起草视频请求，不会发送文字或开始计费操作。使用量读取当前登录账号的消费账单记录，最新消费可能稍后出现。

## 使用本包

余额面板展示当前账号的积分、手机号登录与使用量分析，独立的充值面板负责支付。两页共用现有会话和余额状态；用量查询由积分宿主（`host/credits-index`）确定当前登录账号。

注入的 `creditsSession` 源向其他客户端插件开放同一个账号快照。订阅期间保留共享账号刷新，最后一个订阅释放时停止计时器和焦点监听。退出登录会在等待撤销结果前清除已观察账号，较早的账号或余额读取不能恢复已退出身份，也不能覆盖另一个账号的余额。

桌面欢迎页通过 `?panel=credits` 打开余额面板及手机号登录表单。客户端仅消费一次该入口请求，只从地址中移除 `panel`，保留其他查询参数和 hash。打开页面不会创建账号会话或配置 API Key。短信验证成功后刷新账号会话，并回到现有聊天工作区，不创建或清空其 Session；响应不含注册奖励时也正常完成登录。之后主动打开余额或充值页面、刷新账号或余额，都会保留用户选择的面板。

### 充值

充值接受以元为单位的正整数金额，显示宿主换算后的积分，不把上游 quota 当作积分。创建订单后显示微信二维码，并轮询该订单直到收到终态。读取失败会保留二维码和余额，提示支付结果尚未确认，并可重新读取同一订单的状态，不会创建第二笔订单。停止查询会中止当前 HTTP 读取，但不会取消支付。未知支付状态会停止自动查询并明确提示尚未确认，同时保留同一订单供重新查询。切换订单、账号或关闭面板会丢弃迟到的响应；确认到账后刷新余额。

### 使用量分析

今日、近七天和近三十天均按北京时间自然日统计，截至查询时刻。模型筛选同时作用于消费积分、计费记录和 Token 总量、每日趋势、模型排行及对应明细表。同一周期刷新失败时保留最近成功读取的数值；切换周期后先清除旧数值并显示加载状态。切换账号会卸载上一账号的分析，迟到的响应不会覆盖当前选择。

图表展示退款抵扣前的累计消费、消费账单记录以及 Token 总量。成功且完整的查询中，无记录的日期汇总为零。空响应显示空态；统计不可用、格式异常或数值溢出均显示错误，不编造图表数据。标签、单位和查询状态文案均跟随产品语言与主题。

### 工作区示例

登录后的聊天输入框保留轻量“工作区示例”入口，仅在用户主动打开时展示，介绍用自然语言规划视频分镜、按模型单段时长限制生成，以及裁剪并拼接生成或上传的片段。这个参考弹窗与 AI 在聊天中针对具体请求提出的澄清问题各有用途。Escape、遮罩和关闭均可收起。客户端根内多个已挂载聊天同时最多打开一个示例弹窗；切换账号或卸载输入框会关闭它。状态仅留在内存中，不记录账号已读状态，也不会在首次访问时自动弹出。

选择示例会在打开弹窗时捕获的选区末尾插入普通文本，保留原有文本、引用和附件，不会发送或开始计费操作。草稿版本改变或输入框忙时拒绝插入并显示提示；重新打开示例可获取新的插入位置。

## 模型体验

### 账号面板与工作区示例

#### 模型接收的内容

本包不增加工具或模型调用。`/credits/api/usage` 的读取结果不进入模型输入。工作区示例在用户通过普通聊天输入框发送之前，只是尚未发送的草稿文本。

#### token 影响

账号分析、打开或插入示例均不消耗模型 token。后续 token 用量由常规聊天提交负责。

#### KV Cache 影响

账号分析及尚未发送的示例不改变模型的 KV 缓存。

## 已知限制与延后工作

<a id="known-limitations-and-deferred-work"></a>

- 使用量按当前账号的消费账单记录统计，最新消费可能稍后出现。消费记录数不等于接口请求次数，单独记录的退款不会从累计消费中扣除。本页没有输入输出 Token 拆分和逐次请求流水；部分图片、视频任务没有 Token 用量。宿主以当前账号身份授权读取账单记录。
