# Balance and usage

[English](README.md) | 中文

余额面板展示当前账号的积分、手机号登录与使用量分析，独立的充值面板负责支付。两页共用现有会话和余额状态；用量查询由积分宿主（`host/credits-index`）确定当前登录账号。

## Usage analytics

今日、近七天和近三十天均按北京时间自然日统计，截至查询时刻。模型筛选同时作用于消费积分、计费记录和 Token 总量、每日趋势、模型排行及对应明细表。同一周期刷新失败时保留最近成功读取的数值；切换周期后先清除旧数值并显示加载状态。切换账号会卸载上一账号的分析，迟到的响应不会覆盖当前选择。

图表展示退款抵扣前的累计消费、含任务差额补扣的计费记录以及 Token 总量。成功且完整的查询中，无记录的日期汇总为零。空响应显示空态；统计不可用、未启用、格式异常或数值溢出均显示错误，不编造图表数据。标签、单位和查询状态文案均跟随产品语言与主题。

## Model Experience

本包不增加模型可见内容、工具或模型调用。账号分析只读，不改变 Token 用量或模型的 KV 缓存。

## Known Limitations and Deferred Work

上游按小时汇总的数据通常约有五分钟延迟。计费记录不等于接口请求次数，任务正向补扣可能增加记录，退款也不会从累计消费中扣除。本页没有输入输出 Token 拆分和逐次请求流水；部分图片、视频任务没有 Token 用量。宿主要求上游开启用量统计，并能以当前账号身份授权读取。
