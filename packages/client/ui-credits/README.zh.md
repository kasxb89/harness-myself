# Balance and usage

[English](README.md) | 中文

余额面板展示当前账号的积分、手机号登录与使用量分析，独立的充值面板负责支付。两页共用现有会话和余额状态；用量查询由积分宿主（`host/credits-index`）确定当前登录账号。

桌面欢迎页通过 `?panel=credits` 打开同一个余额面板及手机号登录表单。该跳转不会创建账号会话或配置 API Key。 手机号登录成功后会刷新账号会话，响应不含注册奖励时也正常完成登录。

## Usage analytics

今日、近七天和近三十天均按北京时间自然日统计，截至查询时刻。模型筛选同时作用于消费积分、计费记录和 Token 总量、每日趋势、模型排行及对应明细表。同一周期刷新失败时保留最近成功读取的数值；切换周期后先清除旧数值并显示加载状态。切换账号会卸载上一账号的分析，迟到的响应不会覆盖当前选择。

图表展示退款抵扣前的累计消费、含任务差额补扣的计费记录以及 Token 总量。成功且完整的查询中，无记录的日期汇总为零。空响应显示空态；统计不可用、未启用、格式异常或数值溢出均显示错误，不编造图表数据。标签、单位和查询状态文案均跟随产品语言与主题。

## Model Experience

本包不增加工具或模型调用。账号分析只读，不改变 Token 用量或模型的 KV 缓存。工作区示例在用户通过普通聊天输入框发送之前，只是尚未发送的草稿文本。

## Workspace guide

登录后的聊天输入框保留轻量“工作区示例”入口，仅在用户主动打开时展示，介绍用自然语言规划视频分镜、按模型单段时长限制生成，以及裁剪并拼接生成或上传的片段。这个参考弹窗与 AI 在聊天中针对具体请求提出的澄清问题各有用途。Escape、遮罩和关闭均可收起。客户端根内多个已挂载聊天同时最多打开一个示例弹窗；切换账号或卸载输入框会关闭它。状态仅留在内存中，不记录账号已读状态，也不会在首次访问时自动弹出。

选择示例会在打开弹窗时捕获的选区末尾插入普通文本，保留原有文本、引用和附件，不会发送或开始计费操作。草稿版本改变或输入框忙时拒绝插入并显示提示；重新打开示例可获取新的插入位置。

## Known Limitations and Deferred Work

上游按小时汇总的数据通常约有五分钟延迟。计费记录不等于接口请求次数，任务正向补扣可能增加记录，退款也不会从累计消费中扣除。本页没有输入输出 Token 拆分和逐次请求流水；部分图片、视频任务没有 Token 用量。宿主要求上游开启用量统计，并能以当前账号身份授权读取。
