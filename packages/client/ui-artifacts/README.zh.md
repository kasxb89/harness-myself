# @deepseek-ai/dsh-client-ui-artifacts

[English](README.md) | 中文

## 概述

通过两种范围查找文件：产物库显示配置的输出目录与保留的历史目录；工作区文件浏览已注册的工作区目录。两者显示实际 Host 路径，支持预览和文件管理。工作区文件同时包含原有文件和新建文件，页面不声称每个文件都由某个 Session（会话）生成。

<a id="use-this-package"></a>
## 使用本包

将 `@deepseek-ai/dsh-client-ui-artifacts` 与 slot 和语言服务一起挂载在浏览器插件列表中。配合 [artifacts-index](../../deliverables/artifacts-index/README.zh.md) 提供经过认证的文件访问，工作区注册表提供可选工作区。本包没有配置字段。

产物库读取受管理的输出根目录，并保留原有保存目录设置。点击“保存目录”可在弹窗中查看或修改保存位置；路径和设置在打开弹窗前保持隐藏。弹窗接受已存在的绝对路径，原生文件夹选择器可用时提供选择按钮。保存目录只影响后续生成，已有文件继续可见，不自动移动。选择工作区不会修改该偏好，也不会把工作区根目录写入已保存的输出根目录。

工作区文件优先选择与当前 Session 匹配的已注册工作区；没有匹配时，需要手动选择。按需打开目录，通过面包屑返回上层；搜索只作用于当前目录，并与类型筛选叠加。选定的工作区和完整文件路径说明文件实际在哪里，包括非 Git 工作区内通过 shell 命令创建的文件。移除工作区会撤销通过此浏览器的访问。

两种范围内的文件均可选中后预览、重命名或移入回收区。文件操作携带选定版本的大小与修改时间；文件变化或重名时要求重新检查，不覆盖其他文件。回收区支持恢复，包括重新打开应用之后；工作区文件恢复要求原先的规范工作区目录重新注册。删除需要确认；修改结果未知时，需要先刷新再继续操作。提供服务的 Host 支持相应能力时，页面提供在该 Host 文件管理器中显示选定文件的入口。

图片、视频和音频使用浏览器媒体元素；支持的文本、代码和表格类型使用文本预览。嵌入的原始预览受沙箱隔离。读取失败保留之前数据，并显示重试入口。刷新会将选中文件与当前列表重新匹配，忽略已过时响应。

## 理解实现

<details>
<summary>实现内部细节——点击展开</summary>

浏览器插件通过等待 slot 声明的注册方式贡献 `artifacts` 主面板与侧栏入口。[`ArtifactsPage.tsx`](src/client/ArtifactsPage.tsx) 负责所选范围、工作区、当前目录、搜索、筛选、选择与管理弹窗。注入回调负责 HTTP 操作及可选的原生目录与文件操作。注入的字典提供页面文案；Host 侧为空。

</details>

## 模型体验

### 浏览器呈现

#### 模型看到什么

浏览 `/artifacts/api/list` 或预览不会改变模型请求，也不会向模型提交文件。

#### Token 影响

本包不向模型请求添加文本或文件。

#### KV Cache 影响

本包不组装提供商请求，也不修改模型上下文。

## 已知限制与延期工作

<a id="known-limitations-and-deferred-work"></a>

这些限制说明本包当前的行为与依赖。

- 列表在挂载或用户请求时刷新；页面不订阅文件系统变更。
- 工作区目录按需加载，搜索覆盖当前目录，不递归搜索尚未展开的目录或全部已注册工作区。隐藏目录、依赖目录、私有产物状态目录，以及名称含 `:`、`\` 或控制字符的子目录会被省略。
- 工作区文件是文件浏览器，不是完整的生成记录。原有源文件仍是工作区文件；文件无需经过 `present` 交付，也无需纳入 Git，便可显示。
- 文档、幻灯片、压缩包和其他不支持的类型显示文件信息，不提供转换后的预览。
- 超过 256 KiB 的文本预览或失败的文本读取会回退为框架内的原始 URL；格式呈现取决于浏览器。
- 搜索、筛选与选择属于当前挂载的页面，不会持久化；目录偏好与恢复记录由 Host 保存。
- 重命名或回收不会改写旧聊天链接。回收保留文件字节，不会释放其磁盘空间。不支持安全操作的文件系统无法重命名或回收。
- 路径和原生文件操作均属于提供服务的 Host，远端 Host 的文件不等同于浏览器所在电脑的本地文件；不受该 Host 支持的工作区文件系统映射会被拒绝。
