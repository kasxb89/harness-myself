# @deepseek-ai/dsh-client-ui-artifacts

[English](README.md) | 中文

## 概述

在同一产物库中查找已保存输出和已注册本机工作区内的文件。文件保留在实际 Host 目录中，支持预览和文件管理。工作区内容同时包含原有文件和新输出，列出文件不代表将其归属于某个 Session（会话）。

## 使用本包

将 `@deepseek-ai/dsh-client-ui-artifacts` 与 slot 和语言服务一起挂载在浏览器插件列表中。配合 [artifacts-index](../../deliverables/artifacts-index/README.zh.md) 提供经过认证的文件访问，工作区注册表提供挂载目录。`pollIntervalMs` 控制前台产物库刷新间隔（默认 5000 毫秒，接受范围 1000–60000 毫秒）。可见的产物页定期重查文件、保存目录设置及回收条目，同一时间只执行一轮请求。页面隐藏或卸载时取消未完成的刷新并停止轮询；刷新失败保留已有列表。

产物库合并受管理的输出根目录和已注册本机工作区，包括聊天工具或 shell 命令创建的嵌套文件，不要求纳入 Git 或调用 `present`。点击“保存目录”可在弹窗中查看或修改保存位置；路径和设置在打开弹窗前保持隐藏。弹窗接受已存在的绝对路径，原生文件夹选择器可用时提供选择按钮。保存目录只影响后续媒体生成，已有文件继续可见，不自动移动。注册工作区不会修改该偏好，也不会把工作区根目录写入已保存的输出根目录。

搜索和类型筛选作用于合并后的返回列表，不再提供独立工作区标签或目录导航。移除工作区会撤销该来源的访问。某个来源无法扫描时显示本地化提示，其他文件仍可使用；遍历不完整时另行提示，不将其呈现为完整产物库。

列表不完整时，“查找未列出的文件”打开紧凑的来源与文件夹弹窗。逐层浏览保留输出目录或已注册工作区，选中文件即可在产物库预览中打开。此入口可找到超出首批数量或深度限制的文件，不增加第二个主视图，也不改变保存目录权限。自动刷新在来源仍获授权时保留这些选择；用户主动刷新会清除未返回的按需发现条目，并提示重新从文件夹查找以读取最新元信息。

文件列表行显示名称和元信息；选中文件后，可预览内容、重命名或移入回收区。在预览详情中展开“文件位置”可查看完整 Host 路径，该区域默认折叠。文件操作携带选定版本的大小与修改时间；文件变化或重名时要求重新检查，不覆盖其他文件。回收区支持恢复，包括重新打开应用之后；工作区文件恢复要求原先的规范工作区目录重新注册。删除需要确认；修改结果未知时，需要先刷新再继续操作。提供服务的 Host 支持相应能力时，页面提供在该 Host 文件管理器中显示选定文件的入口。

预览按文件扩展名选择。PDF 使用共享的 PDF.js 阅读器，支持连续分页、文本选择和缩放。DOC/DOCX、XLS/XLSX、PPT/PPTX 通过已授权 Host 的本地 `officeToPdf` 提供方转换为只读 PDF 分页预览，不会将源文件上传至外部文档查看服务。Markdown 使用共享的 `MarkdownText` 渲染器，相对图片以文档所在目录解析，并遵循相同的文件访问授权。纯文本、常见代码与配置文件、CSV/TSV 和字幕提供有大小限制的文本预览，支持的语言使用语法高亮。HTML、HTM 和 SVG 同时受框架沙箱与 Host 响应策略隔离。图片、视频和音频使用浏览器媒体元素，解码失败时显示明确提示。所有格式均提供“下载原文件”。

文本预览最多保留 256 KiB，到达上限后取消后续读取并显示截断提示。读取失败显示错误，不会在框架内加载完整原始文件。Office 转换会提示提供方不可用、内容无效、大小超限、队列繁忙或文件/工作区已变化；缺少原文字体时显示替代字体提示。列表读取失败保留之前数据，并显示重试入口。刷新成功会重新匹配选中文件并重新加载预览，包括同一路径之前失败的预览；已过时响应会被忽略。

## 理解实现

<details>
<summary>实现内部细节——点击展开</summary>

浏览器插件通过等待 slot 声明的注册方式贡献 `artifacts` 主面板与侧栏入口。[`ArtifactsMain.tsx`](src/client/ArtifactsMain.tsx) 从已有会话活动与工作区数据源派生刷新；[`ArtifactsPage.tsx`](src/client/ArtifactsPage.tsx) 负责搜索、筛选、选择与管理弹窗。[`ArtifactPreview.tsx`](src/client/ArtifactPreview.tsx) 负责各格式预览与原文件下载。注入回调负责文件管理 HTTP 操作及可选的原生目录与文件操作。注入的字典提供页面文案；Host 侧为空。

</details>

## 模型体验

### 浏览器呈现

#### 模型看到什么

浏览 `/artifacts/api/list` 或预览不会改变模型请求，也不会向模型提交文件。

#### Token 影响

本包不向模型请求添加文本或文件。

#### KV Cache 影响

本包不组装提供商请求，也不修改模型上下文。

## 已知限制与延期工作

<a id="known-limitations-and-deferred-work"></a>

这些限制说明本包当前的行为与依赖。

- 列表在挂载、用户请求、会话活动或工作区变化以及返回可见聚焦窗口时刷新。页面没有文件系统订阅或轮询循环。
- 搜索覆盖 Host 遍历限制内返回的文件，文件夹弹窗可访问首批递归扫描之外的内容。隐藏目录、依赖目录、私有产物状态目录和符号链接路径会被排除。明确保存到全部受管理输出根目录和已注册工作区之外的文件，不属于此产物库范围。
- 产物库显示当前文件系统内容，不是完整的生成历史。原有源文件仍是普通工作区文件；文件无需经过 `present` 交付，也无需纳入 Git，便可显示。
- Office 预览依赖提供服务的 Host 上的本地转换提供方，显示 PDF 分页，不提供文档编辑器或可编辑表格网格。字体替代可能改变排版。
- PDF 预览遵循共享[文档阅读器的限制](../ui-sidebar-documentpreview/README.zh.md)。媒体播放取决于浏览器对编码的支持。压缩包、未知二进制格式和不支持的媒体编码不提供内嵌预览，可下载原文件后使用兼容应用打开。
- 搜索、筛选与选择属于当前挂载的页面，不会持久化；目录偏好与恢复记录由 Host 保存。
- 重命名或回收不会改写旧聊天链接。回收保留文件字节，不会释放其磁盘空间。不支持安全操作的文件系统无法重命名或回收。
- 路径和原生文件操作均属于提供服务的 Host，远端 Host 的文件不等同于浏览器所在电脑的本地文件；不受该 Host 支持的工作区文件系统映射会被拒绝。
