# AI 提示词帮写

[English](README.md) | 中文

## 概述

`@deepseek-ai/dsh-client-ui-prompt-assist` 的参考文档。该包为图片和视频创作主提示词旁提供共享的帮写与修改操作。会话可选作用域的 `creation.prompt.assist` 工厂在每个渲染位置独立管理修改建议与操作状态。[Slots 参考](../../../docs/subsystems/slots.zh.md)定义工厂的组合方式。

## 使用此包

调用方提供创作类型、当前主提示词、所有相关图片素材标识符、生成参数、账号标识与可用状态。点击“AI 帮写”会立即读取这些内容并请求新提示词，成功后直接写入主输入框。用户可以继续在主输入框手动编辑。“调整要求”按需展开修改建议输入框和“按建议修改”操作，收起时保留已填写的要求。帮写、读取素材数量和等待中的停止操作始终可见。素材统一由创作区的单一入口上传、预览和移除。

`onPromptChange(next, expectedPrompt)` 供调用方在替换文字前，原子核对当前草稿与创作上下文。返回 false 时保留当前草稿和建议，并提示未覆盖内容。`onBusyChange` 只报告实际操作的开始与结束。调用方用它禁止同时上传素材或生成作品，同时保持主提示词可编辑；不能将同一个 busy 标记反向传入工厂的 `disabled`，后者只表示外部上传或媒体生成状态。

同一个 AbortController 管理账号核验、模型提交与最终账号核验。浏览器每次账号核验最多等待 15 秒，模型最多等待 130 秒，后者留出了 Host 支持的最长时限。到期后即使传输未结束，也会中止等待并释放 busy 状态。Host 也会在发送模型请求前独立核对预期账号。只有两次账号核验成功、调用方上下文仍一致且最终回调接受替换时，组件才写入文字。修改主提示词、素材、参数、账号、会话或聊天模型，以及取消或卸载组件，都会中止等待并丢弃迟到结果。只有仍持有操作所有权的请求会释放 busy 标记。错误和被拒绝的替换保留主草稿与修改建议；修改成功后清空建议字段。提交后超时会明确提示结果未知且可能计费，不会自动重试。

请求将当前主提示词、去重图片标识符、生成参数、预期账号标识符、会话与聊天模型选择 POST 到 `/credits/api/prompt/assist`。Host 独立读取会话选择或当前聊天默认模型，核对当前账号目录中的完整提供商和模型身份，并在提交与接受结果前复核本地选择。浏览器提供的预期选择不决定路由。首次帮写的 instruction 为空，修改时发送用户建议。浏览器不接收或提交 API Key。帮写和修改均不会触发图片或视频生成。

<a id="model-experience"></a>
## 模型体验

### 提示词帮写与修改

#### 模型看到什么

用户明确点击帮写并通过 `/credits/api/prompt/assist` 请求后，Host 接收当前主提示词、创作区图片标识符和生成参数。修改时额外接收用户建议。Host 验证图片，并使用当前产品账号下的当前聊天模型。视频帮写应用共享的编导技能要求，覆盖剧情节拍、分镜、人物与素材连续性、对白、可见口型和字幕时间。显示操作按钮、填写建议或手动编辑主提示词均不请求模型。

#### Token 影响

提示词最多 7000 字符，修改建议最多 2000 字符。AI 帮写最多读取九张图片素材，单张最多 6 MiB，合计最多 12 MiB；Host 在请求前校验完整字节大小。每次帮写或修改都可能消耗当前账号的 AI 额度。

#### KV Cache 影响

每次帮写都是独立的 Host 请求。客户端不保留模型对话，也不管理提供商缓存。

## 已知限制与延后工作

<a id="known-limitations-and-deferred-work"></a>

- 修改建议仅保留在挂载的工厂实例中，应用刷新或面板卸载后不保留。
- 模型请求发出后停止等待，无法保证请求尚未处理或计费；在首次账号核验时停止不会请求模型。
- AI 帮写使用当前选中的产品账号聊天模型。其他提供商的模型会被拒绝，避免将其名称与产品账号凭据组合发送。素材图片要求模型明确声明图片输入能力；Host 不会自动换用另一个模型。
