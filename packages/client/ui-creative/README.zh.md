# 创作项目

[English](README.md) | 中文

## 概述

在聊天右侧管理图片、视频项目，包括从 AI 创作发起的作品。编辑分镜时长和顺序、维护人物及参考素材，查看保留任务和真实产物。规划修改直接保存，不请求模型。生成和重构使用普通聊天草稿与已有原生流程。视频文件保存完成与人声、口型、字幕同步是否通过核验分别显示。

## 使用方式

公开模型目录声明音频模型后，AI 创作主页面会提供音频入口。选择该模型支持的音色、格式，填写朗读文本及已声明支持的语速或语气要求，先免费估价，再点击显示金额的确认按钮生成。修改参数、切换账号或聊天、报价过期都会清除估价。每次确认生成一条独立音频，之前未完成的任务不阻挡新请求；查询只读取原任务，不会再次生成。保存的文件可直接播放和下载。音频已保留但尚未写入产物目录时，仍可播放、下载，并使用「重新保存到产物目录」恢复原文件；该操作不请求上游、不重新生成或扣费。

API 调用和媒体渲染通过 [`appPath`](../ui-primitives/README.zh.md#use-this-package) 保留应用部署前缀；归属校验仍检查 Host 原始路径。

在聊天现有右侧栏打开 **创作**。每个聊天保留其选中的项目和镜头，也包含 AI 创作关联到该聊天的项目。首个真实项目会展开一次侧栏标签；后续进度不会重新打开用户关闭的标签。人物、素材、分镜和任务分别显示，较长设定折叠在详情中。

缩略图时间轴显示计划起止时间。选择镜头查看详情、前后移动，并编辑标题、时长、运镜、场景、动作、提示词、对白、字幕及人物和素材关联。人物与素材卡支持搜索、添加和编辑；素材上传保留真实本机引用标识。保存免费，并检查计划版本。并发修改冲突时保留表单并提示刷新；正在执行的关联条目不能改写。计划时长与最近提交的生成时长分别保留。

素材上传支持常见图片格式，包括 HEIC、TIFF 与动态 GIF。Host 自动转为模型支持的 PNG/JPEG，并返回转换后大小及经过授权的预览；动态图或多页图片使用第一帧。编辑器显示失败的文件名和原因，保留原素材，并允许再次选择同一文件。素材卡与编辑器顶部均有明确上传入口；每个素材编辑器一次上传一个来源。人物卡与编辑器支持一次上传多张参考图，显示预览并自动勾选。保存时，图片素材与人物绑定在同一次版本检查下写入；引用该人物的镜头会通过原生流程使用真实图片。后续图片上传失败时保留已成功的图片与勾选，关闭编辑器会取消尚未执行的上传队列。

任务区按保留调用状态和产物类型筛选，显示已完成镜头数量，并打开实际保存的参考图、片段和成片。失败与结果未知任务仍可查看，较早的可用产物继续保留。数量来自已提交的本机记录，不估算上游渲染百分比。

图片任务保留提交回执。Host 授权查询已有任务编号时，**查询原任务** 读取该任务，不再次提交生成；查询受理后继续读取可见任务进度。对于 Host 已经私密留存的同步结果，任务卡改为提供 **继续保存原图**，即使提供方没有返回任务编号也可使用。该操作保存原结果并复用已经核对的保存检查点，不再次生成，也不查询提供方任务。回执详情显示已保留的任务和请求编号，不暴露凭据、后端地址、结果签名 URL 或内联图片数据。

只有 Host 已提交有归属的原始结果，重启后才能继续恢复保存。私有结果缺失、留存中断或签名 URL 过期时会明确显示恢复失败，不会启动另一笔生成。没有归属留存结果的旧调用仍需核对原任务及计费。保存检查点覆盖已经登记的文件，不将产物发布与私有记录合并为一个事务，也不保证所有崩溃位置都只有一份物理文件。Host 可配置的响应和单图字节预算还可能在结果可恢复前拒绝该结果，详见[图片留存限制](../../host/credits-index/README.zh.md#use-this-package)。

预览只使用经过所有者授权的真实文件。视频帧网格展示实际提取的帧与时间点；尚未提取或提取失败会明确提示，原文件仍可下载。文件完成与同步核验分别显示：已保存的视频仍将人声、口型和字幕同步标为待核验。

**修改人物**、**重构素材** 与 **修改镜头** 共用填写修改要求的弹窗。**重做镜头** 将原项目和镜头标识写入可编辑的聊天草稿。每种操作均保留正常发送步骤，自身不会发起付费请求；发送草稿后可能执行生成并消耗积分。人物和素材修改保留原计划成员标识，检查真实引用与模型支持。没有来源的图片素材可先依据描述生成；已有来源不可读或并非图片时，先核对输入或处理方式。素材卡展示实际保存的产物，人物卡只预览已登记引用素材的真实图片。草稿正在提交或发生冲突时，写入会被拒绝，用户文字不会被覆盖。图片项目的产物分区显示为 **作品**。

随产品交付的 Web 应用组合此浏览器插件。Loader 配置控制可见活动项目的读取频率：

| 字段 | 默认值 | 含义 |
|---|---|---|
| `pollIntervalMs` | `2000` | 活动项目读取间隔，范围为 500 到 60000 毫秒。 |

读取失败保留最近可用的项目，并提供重试操作。隐藏已打开的标签或应用会停止轮询。首个项目出现前，已记录的媒体工具调用会监督读取，直到真实记录可用；空响应不会编造计划或进度。工具结果和回合结束会停止空列表监督。会话工具状态变更、重新打开及连接重置会读取完整最新列表。退出登录立即清除全部项目快照；先前账号的迟到响应不能重新填入数据。

已知受理的任务在排队或临时读取、保存失败后仍显示生成中。任务卡为可查询的回执提供 **查询原任务**，为 Host 已留存的原图结果提供 **继续保存原图**；两者都恢复同一作品，不再次生成。受理情况未知时明确保留待确认状态，不自动重提。失败任务卡显示本地化的繁忙提示，并提醒先核对已有结果再提交，不将任务诊断代码呈现给用户。已保存但未能加入产物库的文件保留独立的本地存储恢复提示，并且仍可预览。

已保存的视频产物使用[共享播放器](../ui-primitives/README.zh.md#video-playback)，显示可拖动的进度条。

## 实现原理

<details>
<summary>实现细节——点击展开</summary>

插件注册一个普通右侧栏标签。注册拥有的[控制器](src/client/controller.ts)管理可取消的会话读取、免费版本校验保存及素材上传。框架绑定的观察源钩子向标签提供数据。[传输解析器](src/client/api.ts)校验项目、任务及媒体归属；侧栏不扫描聊天文字来编造状态。

权威 Credits 账号观察源提供登录状态。账号、会话及应用可见性变化会取消过期读取，账号世代号隔离迟到响应。标签生命周期拥有可见性保留，控制器拥有轮询并在卸载时等待读取结束。草稿写入结果显示在不会随请求标签关闭而消失的全局提示中。

</details>

## 模型体验

### 创作修改草稿

#### 模型看到什么

查看、刷新、查询原图片任务、免费字段修改、上传和下载文件不会请求模型。音频生成仅将用户输入的朗读文本和语音参数交给所选语音模型，不发送聊天历史，也不创建隐藏聊天消息。AI 修改与镜头重做会将本地化文字、准确的计划和成员标识以及用户要求写入普通聊天草稿。发送后模型才会看到这些内容；草稿要求调用 `get_creation_plan`、保留无关成员，并使用已有原生生成和剪辑工具。时间轴和引用修改通过已记录的计划读取成为模型输入，不添加隐藏消息。

#### Token 影响

下一条用户主动发送的消息包含写入的要求。本包不会添加隐藏的会话消息或后台模型调用。

#### KV Cache 影响

缓存由普通会话提交路径管理。读取进度和预览文件不会改变会话上下文。

## 已知限制与待办

<a id="known-limitations-and-deferred-work"></a>

侧栏展示已保留的项目事实与真实文件，存在以下限制：

- 音频生成需要公开能力明确声明已核验的音色、格式、文本上限与执行及报价协议；型号名称和管理员专用预览不能启用生成。结果待确认不代表退款，缺少原任务编号且没有其他已授权结果来源时不能恢复。
- 没有登记创作计划的旧聊天不会显示重建分镜；不会解析普通回复文字来编造计划。
- 结果未知，且没有保留任务编号或完整归属图片结果的提交，无法在此界面恢复；只有请求编号也不允许再次提交生成。
- 引用设定不能保证上游维持人物外观、对白或口型同步。
- 成片检查完成前，同步状态仍为待核验；保存文件不等于取得核验结果。
- 预览提取可能独立于生成失败，已保存的原始产物仍可使用。
