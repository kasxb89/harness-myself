# 产品手机号登录替代官方账号引导

[English](guide.md) | 中文

## 变更

桌面产品此前接受 DeepSeek 官方账号或已配置的提供方 API Key 来通过欢迎页。现在，启动状态由产品手机号会话决定。已有有效手机号会话会直接打开工作区，无需再次登录；否则，智澍科技欢迎页提供**手机号登录**，点击后打开**余额**登录表单。

产品默认停用官方账号界面和自动 API Key 引导。已有提供方凭据继续保存在本地，但不能代替产品登录。手机号登录后端提供该账号的专属中转凭据，用户无需手动填写此 Key。

## 迁移

1. 重启升级后的产品。如果出现欢迎页，选择**手机号登录**，在**余额**中使用已有产品账号完成手机号验证。
2. 保留已有提供方凭据，无需迁移凭据文件。如果旧手机号会话在生成时报告 `RELAY_MISSING`，在**余额 → 退出登录**后重新登录一次，获取该账号的中转凭据。
3. 自定义 profile 覆盖配置应保持 `ui-settings-account` 停用，并将 `ui-settings-models.config.credentialOnboarding` 设为 `false`，使官方登录和自动 Key 表单保持隐藏。
4. 确认**余额**显示自己的账号和余额，然后重启。有效手机号会话应直接打开工作区；未登录时的欢迎页应显示产品名称和手机号登录入口，不再显示 DeepSeek HARNESS 标志或**添加 API Key**。
