# 产品模型容量由后台管理

[English](guide.md) | 中文

## 变更

产品账号模型同步器为已核实的 `context_window` 和 `max_output_tokens` 添加本地 `managedLimits.authoritative: true` 标记。这些容量优先于已保存的模型级 `contextWindow` 和 `maxTokens`，包括旧客户端保存的较小值。目录刷新后，已有聊天的后续请求采用新容量。较小的逐次请求预算和 SDK 上下文余量继续限制每次请求。

标记要求后台与账号归属一致。旧版无版本目录在字段缺失或无效时保留同一归属最后核实的容量。带版本的型号必须提供同一次发布中完整且已核实的有效上下文／输出数量；元数据不完整或交叉时停止更新，不借用其他数值。后台从未声明的容量继续采用原有回退。产品账号同步器之外的提供方路由维持原有手工容量行为。

## 迁移

1. 在后台模型设置中，按已核实的渠道限制填写每款产品模型的上下文窗口和最大输出。
2. 升级客户端后打开模型选择器，或等待已有的 60 秒目录刷新完成。客户端无需手工修改容量。
3. 在原聊天发送下一条消息，核对请求选项和实际渠道请求的输出预算。较小的显式请求预算和剩余上下文仍会限制实际值。

已存手工容量保留在 profile 中。特定请求需要较小预算时，使用该请求的 `maxTokens` 控件。
