# 产品产物保存目录管理

[English](guide.md) | 中文

## 变更

产品组合现在提供统一的产物保存服务。新图片与单段视频默认仍位于 `<Harness home>/plugin-data/credits/media`，用户可在产物页更改。新视频项目与本地视频剪辑也会在工作区沙箱完成剪辑后，将成片发布到此目录。工具返回发布路径。没有捕获发布目录字段的旧项目记录在恢复时保留原有工作区目标。已有文件与聊天链接不自动迁移或改写。

## 迁移

1. 在产物页查看当前保存目录。若要使用其他位置，选择已存在且可写的目录并保存。更改只影响后续操作，在途操作继续使用已捕获的目标。
2. 自定义组合可设置 `@deepseek-ai/dsh-artifacts-index` 的 `defaultOutputDirectory` 与 `stateDirectory`，并提供经过认证的 `connection`。私有状态目录必须与全部输出根目录分开。不提供统一保存服务时，credits host 保留原有输出行为。
3. 生成或保存文件，确认返回路径位于所选目录且出现在产物页。之前配置和选择过的根目录继续可见。重命名或回收会更改文件路径；可在回收区恢复到原位置。
