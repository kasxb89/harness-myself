# 带版本的模型配置与视频项目

[English](guide.md) | 中文

## 变更

新视频项目的私有 manifest 使用 `version: 2`。旧客户端只接受版本 1，会在提交生成前拒绝这些新记录。当前客户端可读取两个版本，并在保存时保留记录原有版本；既有版本 1 项目不会被迁移，也不会被补上今天的模型配置。

已发布的模型版本将每款模型已核实的有效上下文／输出上限、价格及图片／视频参数绑定在一起。配置变化会停止尚未提交的操作，不会静默更换模型、价格或规格。已受理或不确定的任务编号仍可用于恢复原任务。上下文与输出数量分别对应模型能力，并不要求相等或按固定比例计算。

## 迁移

1. 保留既有账号登录、私有项目记录和已存素材。不要删除它们，也不要编辑 manifest 的 `version`、模型版本或预备请求。
2. 使用当前客户端恢复版本 2 项目。降级旧客户端后不能恢复该项目；当前客户端仍可读取原版本 1 项目。
3. 后台发布配置后刷新模型目录，确认精确型号支持的规格和有效上限。如果配置冲突使请求停止，先核对原任务历史，再明确发起其他操作；刷新或充值均不会自动重复 POST。

目录核对、版本回执与恢复行为见[账号与创作包](../../../../packages/host/credits-index/README.zh.md)。
