# 充值后继续视频作品

[English](guide.md) | 中文

## 变更

此前，保留的视频作品可能因未提交的余额不足而永久失败。客户端现在在私有视频项目和创作记录中保留余额拒绝证明及尝试历史。较晚的真人消息或提问卡回答可以授权在原作品中发起新尝试。已受理任务及已保存片段保持原有标识。

旧记录仍可读取。缺失证明不表示任务未提交。有原任务时，恢复会读取它；未确认或已受理的提交不能通过余额重试路径重复。旧客户端无法提供新的恢复行为。

## 迁移

1. 保留现有私有项目记录、创作记录及已保存媒体，不要通过清空它们来移除失败状态。
2. 充值后，在原聊天明确要求继续原作品。创建独立新尝试前，客户端会重新核对原任务证明及当前提交授权。单独的支付确认不会重新生成。
3. 确认原项目仍被保留、已保存片段被复用。如果原提交结果仍未知，请保留其任务标识用于核对，不要再次提交。
