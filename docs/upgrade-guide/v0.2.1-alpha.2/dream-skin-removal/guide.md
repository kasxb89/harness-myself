# Remove an independently installed Dream Skin

English | [中文](guide.zh.md)

## Change

Earlier product packages included `dsh-dream-skin`, which provided Theme / Appearance alongside Skin market. The product no longer distributes Dream Skin; Skin market remains the skin-selection entry, and the core theme service remains available. Upgrading the product does not automatically remove a copy independently installed in a user's profile.

## Migration

1. Open Plugins from the sidebar and check the installed plugins for `dsh-dream-skin` / Dream Skin. If it is not independently installed, no removal is needed.
2. If present, select Uninstall for Dream Skin and confirm. Use the normal plugin manager so the profile installation is removed.
3. Confirm that Theme / Appearance is absent and Skin market remains available. Select skins through Skin market.
