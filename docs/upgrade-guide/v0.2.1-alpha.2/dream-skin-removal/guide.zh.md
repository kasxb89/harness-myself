# 卸载独立安装的 Dream Skin

[English](guide.md) | 中文

## 变更

之前的产品包包含 `dsh-dream-skin`，在皮肤市场之外提供 Theme / 外观入口。产品不再分发 Dream Skin，保留皮肤市场作为皮肤选择入口，并保留核心主题服务。升级产品不会自动删除用户 profile 中独立安装的副本。

## 迁移

1. 在侧边栏打开“插件”，在已安装插件中查找 `dsh-dream-skin` / Dream Skin。没有独立安装时，无需卸载。
2. 如有该插件，点击 Dream Skin 的“卸载”并确认，通过正常插件管理移除 profile 中的安装。
3. 确认 Theme / 外观入口已消失，皮肤市场仍可打开；后续通过皮肤市场选择皮肤。
